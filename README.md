# 鸡同鸭讲 - 网页版

> 一款 2-4 人联机合作派对游戏。玩家被赋予不同的"感官缺陷"身份（哑巴/聋子/盲人），必须通过有限的、非精确的交流方式协作完成日常任务。

（首次部署后填入）

## 🚀 怎么玩

### 手机玩

1. 打开链接（建议加到主屏幕，体验更接近 App）
2. 一个人点"创建房间" → 生成 6 位房间号
3. 朋友打开同样链接 → 输入房间号 → 加入
4. 至少 2 人时，房主点"开始游戏"

### 电脑玩

- 鼠标：左半屏点击拖动 = 移动，右半屏拖动 = 视角
- 键盘：WASD 移动（暂不支持鼠标视角，调试中）

## 🛠️ 技术栈

- **前端**：纯 HTML + JavaScript（无构建步骤）
- **3D**：Three.js
- **联机**：PeerJS（WebRTC 包装）+ 公共 broker（**零服务器**）
- **部署**：GitHub Pages（**零成本**）

## 🎮 角色设计

| 角色 | 能力 | 限制 |
|------|------|------|
| 哑巴厨师长 | 看到完整任务信息 | 不能说话/打字 |
| 聋子传令官 | 可以说话/打字 | 听不到任何语音 |
| 盲人执行者 | 能操作所有任务道具 | 看不到颜色/文字/标签 |

**信息传递链**：哑巴（看菜谱）→ 画板/动作轮盘 → 聋子（接收图）→ 语音转述 → 盲人（执行操作）
